Get an API token, synthesise a sentence, and hear it back.

## Prerequisites

- A Voho account at [app.voho.ai](https://app.voho.ai)
- `curl`, or Python/Node if you prefer

## Get a token

<Steps>
  <Step title="Open the console">
    Sign in at [app.voho.ai](https://app.voho.ai) and go to API tokens.
  </Step>
  <Step title="Create a token">
    Give it a name that says where it will be used — `billing-service`, `ivr-staging`. When a token needs revoking, you will want to know what breaks.
  </Step>
  <Step title="Copy it now">
    The token is shown once and starts with `voho_sk_live_`.

    <Warning>
      Only the hash is stored, so a lost token cannot be recovered — you would create a new one and revoke the old. Put it in your secret manager before closing the page.
    </Warning>
  </Step>
</Steps>

```bash
export VOHO_API_KEY="voho_sk_live_..."
```

## Your first request

<CodeGroup>
```bash cURL
curl -X POST https://app.voho.ai/v1/speech \
  -H "Authorization: Bearer $VOHO_API_KEY" \
  -H "Content-Type: application/json" \
  -d '{
    "text": "أهلاً بك في فوهو، كيف أقدر أساعدك؟",
    "voice": "layla"
  }' \
  --output hello.mp3
```

```python Python
import os, requests

r = requests.post(
    "https://app.voho.ai/v1/speech",
    headers={"Authorization": f"Bearer {os.environ['VOHO_API_KEY']}"},
    json={"text": "أهلاً بك في فوهو، كيف أقدر أساعدك؟", "voice": "layla"},
)
r.raise_for_status()
open("hello.mp3", "wb").write(r.content)
```

```javascript Node
import fs from "node:fs/promises";

const res = await fetch("https://app.voho.ai/v1/speech", {
  method: "POST",
  headers: {
    Authorization: `Bearer ${process.env.VOHO_API_KEY}`,
    "Content-Type": "application/json",
  },
  body: JSON.stringify({
    text: "أهلاً بك في فوهو، كيف أقدر أساعدك؟",
    voice: "layla",
  }),
});

if (!res.ok) throw new Error((await res.json()).error.message);
await fs.writeFile("hello.mp3", Buffer.from(await res.arrayBuffer()));
```
</CodeGroup>

Play `hello.mp3`. That is `layla` in Najdi Arabic on the default model.

## Find a different voice

The catalog is browsable by dialect, which is usually the first thing you want to filter on.

```bash
curl "https://app.voho.ai/v1/voices?dialect=najdi" \
  -H "Authorization: Bearer $VOHO_API_KEY" | jq '.voices[] | {id, name, gender, styles}'
```

Any voice ID drops straight into the `voice` field. See [Voices and languages](/voices) for the full catalog.

## For telephony

If the audio is going onto a phone line, ask for `mulaw` at 8 kHz — that is what SIP trunks carry, so you skip a transcoding step:

```bash
curl -X POST https://app.voho.ai/v1/speech \
  -H "Authorization: Bearer $VOHO_API_KEY" \
  -H "Content-Type: application/json" \
  -d '{"text":"أهلاً بك","voice":"layla","format":"mulaw"}' \
  --output prompt.ulaw
```

## For live conversation

Waiting for a complete file adds its whole synthesis time to the silence a caller hears. Stream instead — first audio arrives in roughly 200 ms rather than 1.7 s:

```bash
curl -N -X POST https://app.voho.ai/v1/speech/stream \
  -H "Authorization: Bearer $VOHO_API_KEY" \
  -H "Accept: text/event-stream" \
  -H "Content-Type: application/json" \
  -d '{"text":"أهلاً بك","voice":"layla","format":"opus"}'
```

If your text comes from an LLM and arrives incrementally, use the [WebSocket](/api-reference/websocket) — it accepts text while audio is already playing.

## Check before you ship

Run your templates through [`/v1/text/normalize`](/api-reference/text-normalize) once to see how numbers and currency will actually be spoken. Expansion is where most pronunciation surprises live.

```bash
curl -X POST https://app.voho.ai/v1/text/normalize \
  -H "Authorization: Bearer $VOHO_API_KEY" \
  -H "Content-Type: application/json" \
  -d '{"text":"المبلغ SAR 1,250 مستحق في 15/03."}'
```

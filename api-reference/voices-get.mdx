Everything needed to configure one voice, including a ready-to-send sample request in the right language.

<RequestExample>
```bash cURL
curl https://app.voho.ai/v1/voices/layla \
  -H "Authorization: Bearer $VOHO_API_KEY"
```
</RequestExample>

<ResponseExample>
```json Response
{
  "id": "layla",
  "name": "Layla",
  "gender": "female",
  "age": "18-30",
  "language": "ar-SA",
  "dialect": "najdi",
  "country": "Saudi Arabia",
  "styles": ["Professional", "Formal"],
  "description": "Warm Najdi delivery. The default for inbound reception and appointment setting.",
  "supported_models": ["sada-1", "nabra-1"],
  "sample_request": {
    "text": "أهلاً بك في فوهو",
    "voice": "layla",
    "model": "sada-1",
    "format": "mp3"
  }
}
```

```json Unknown voice
{
  "error": { "code": "unknown_voice", "message": "Unknown voice \"nope\"." }
}
```
</ResponseExample>

<Tip>
  `sample_request` is a complete body you can post straight to [`/v1/speech`](/api-reference/speech) — useful for auditioning a voice without writing anything.
</Tip>

For the full catalog with descriptions, see [Voices and languages](/voices).

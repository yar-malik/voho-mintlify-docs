<Info>
  **GET** `https://app.voho.ai/v1/voices`
</Info>

Returns the voice catalog along with the models, formats, and streaming capabilities available to you. The catalog is meant to be browsed by dialect first.

## Query parameters

<ParamField query="dialect" type="string">
  `najdi`, `gulf`, `hijazi`, `msa`, or `egyptian`.
</ParamField>

<ParamField query="gender" type="string">
  `female` or `male`.
</ParamField>

<ParamField query="language" type="string">
  Language prefix, matched against the start of the locale — `ar` matches `ar-SA`, `ar-AE`, and `ar-EG`.
</ParamField>

<ParamField query="style" type="string">
  `Professional`, `Formal`, `Casual`, or `Energetic`.
</ParamField>

Filters combine with AND.

## Response

<ResponseField name="object" type="string">Always `list`.</ResponseField>
<ResponseField name="count" type="integer">Number of voices after filtering.</ResponseField>
<ResponseField name="dialects" type="array">Available dialects with display labels.</ResponseField>
<ResponseField name="models" type="array">Model `id`, `name`, and `description`.</ResponseField>
<ResponseField name="formats" type="array">Format `id`, `content_type`, and `default_sample_rate`.</ResponseField>
<ResponseField name="streaming" type="object">Streaming `endpoint`, `model`, and supported `formats`.</ResponseField>
<ResponseField name="voices" type="array">
  <Expandable title="voice">
    <ResponseField name="id" type="string">Identifier used in synthesis requests.</ResponseField>
    <ResponseField name="name" type="string">Display name.</ResponseField>
    <ResponseField name="gender" type="string">`female` or `male`.</ResponseField>
    <ResponseField name="age" type="string">`18-30`, `30-50`, or `60+`.</ResponseField>
    <ResponseField name="language" type="string">BCP-47 locale.</ResponseField>
    <ResponseField name="dialect" type="string">Arabic dialect, or `none` for non-Arabic voices.</ResponseField>
    <ResponseField name="country" type="string">Country or region.</ResponseField>
    <ResponseField name="styles" type="array">Delivery styles.</ResponseField>
  </Expandable>
</ResponseField>

<RequestExample>
```bash All voices
curl https://app.voho.ai/v1/voices \
  -H "Authorization: Bearer $VOHO_API_KEY"
```

```bash Najdi only
curl "https://app.voho.ai/v1/voices?dialect=najdi" \
  -H "Authorization: Bearer $VOHO_API_KEY"
```

```bash Female, professional
curl "https://app.voho.ai/v1/voices?gender=female&style=Professional" \
  -H "Authorization: Bearer $VOHO_API_KEY"
```
</RequestExample>

## Get a voice

<Info>
  **GET** `https://app.voho.ai/v1/voices/{id}`
</Info>

Everything needed to configure one voice, including a ready-to-send sample request in the right language.

<RequestExample>
```bash cURL
curl https://app.voho.ai/v1/voices/layla \
  -H "Authorization: Bearer $VOHO_API_KEY"
```
</RequestExample>

<ResponseExample>
```json Response
{
  "id": "layla",
  "name": "Layla",
  "gender": "female",
  "age": "18-30",
  "language": "ar-SA",
  "dialect": "najdi",
  "country": "Saudi Arabia",
  "styles": ["Professional", "Formal"],
  "description": "Warm Najdi delivery. The default for inbound reception and appointment setting.",
  "supported_models": ["sada-1", "nabra-1"],
  "sample_request": {
    "text": "أهلاً بك في فوهو",
    "voice": "layla",
    "model": "sada-1",
    "format": "mp3"
  }
}
```

```json Unknown voice
{
  "error": { "code": "unknown_voice", "message": "Unknown voice \"nope\"." }
}
```
</ResponseExample>

<Tip>
  `sample_request` is a complete body you can post straight to [`/v1/speech`](/api-reference/speech) — useful for auditioning a voice without writing anything.
</Tip>

For the full catalog with descriptions, see [Voices and languages](/voices).

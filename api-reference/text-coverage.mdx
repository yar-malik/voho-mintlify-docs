---
openapi: "POST /v1/text/coverage"
title: "Check pronunciation coverage"
sidebarTitle: "Coverage"
description: "Flag tokens likely to be mispronounced."
---

Flags tokens likely to be mispronounced: Latin words inside Arabic text, unexpanded digits, asset tags, and acronyms.

<Warning>
  This is a lexical check, not a pronunciation model. It tells you where a pronunciation hint is probably needed; it does not know how your asset codes are meant to sound.
</Warning>

<ParamField body="text" type="string" required>
  Text to check.
</ParamField>

### Flag reasons

| Reason | Meaning |
| --- | --- |
| `asset_tag` | Looks like an equipment code — spell out or supply a hint |
| `acronym` | Will be read letter by letter unless hinted |
| `contains_digits` | Will be expanded; the hint shows how |
| `latin_in_arabic` | Latin word inside Arabic text; confirm the intended reading |

<RequestExample>
```bash cURL
curl -X POST https://app.voho.ai/v1/text/coverage \
  -H "Authorization: Bearer $VOHO_API_KEY" \
  -H "Content-Type: application/json" \
  -d '{"text":"عطل في المكيف AC-4417 في مبنى HVAC"}'
```
</RequestExample>

<ResponseExample>
```json Response
{
  "language": "ar",
  "token_count": 6,
  "flagged_count": 2,
  "coverage": 0.667,
  "flagged": [
    {
      "token": "AC-4417",
      "reason": "asset_tag",
      "hint": "Spell out or supply a pronunciation hint."
    },
    {
      "token": "HVAC",
      "reason": "acronym",
      "hint": "Will be read letter by letter unless a hint is supplied."
    }
  ]
}
```
</ResponseExample>

`coverage` is the proportion of tokens that raised no flag — 1.0 means nothing looked risky. Treat it as a smoke test on a batch of templates, not a quality score.

The Voho API covers speech, agents, and the endpoints that read something rather than say it. Every endpoint lives under one base URL, takes the same bearer token, and draws down the same credit balance.

```
https://app.voho.ai
```

## Authentication

Every request needs an API token in the `Authorization` header.

```bash
curl https://app.voho.ai/v1/voices \
  -H "Authorization: Bearer voho_sk_live_..."
```

Tokens are created in the Voho console and begin with `voho_sk_live_`.

<Warning>
  The plaintext token is shown **once**, at creation. Only its hash is stored, so a lost token cannot be recovered. Create a new one and revoke the old. Revoking takes effect immediately.
</Warning>

A missing, malformed, or revoked token returns `401`:

```json
{ "error": { "code": "unauthorized", "message": "Invalid or missing API token." } }
```

## Endpoints

| Method | Path | Purpose |
| --- | --- | --- |
| `POST` | [`/v1/speech`](/api-reference/speech) | Synthesise a complete audio file |
| `POST` | [`/v1/speech/stream`](/api-reference/speech-stream) | Stream audio as it is generated |
| `WS` | [`/v1/speech/ws`](/api-reference/websocket) | Incremental text in, audio out, one connection |
| `GET` | [`/v1/voices`](/api-reference/voices-list) | List and filter the voice catalog |
| `GET` | [`/v1/voices/{id}`](/api-reference/voices-get) | Details for one voice |
| `POST` | [`/v1/text/normalize`](/api-reference/text-normalize) | See how text will be spoken |
| `POST` | [`/v1/text/coverage`](/api-reference/text-coverage) | Flag likely mispronunciations |
| `GET` | [`/v1/agents`](/api-reference/agents-list) | List the agents on your account |
| `POST` | [`/v1/agents/{id}/reply`](/api-reference/agents-reply) | What the agent says next |
| `POST` | [`/v1/transcribe`](/api-reference/transcribe) | Turn a clip into text |
| `POST` | [`/v1/documents/extract`](/api-reference/documents-extract) | Fields out of a document |
| `POST` | [`/v1/documents/ask`](/api-reference/documents-ask) | A question answered, with quotes |
| `POST` | [`/v1/privacy/redact`](/api-reference/privacy-redact) | What would leave your estate |
| `POST` | [`/v1/facilities/work-order`](/api-reference/facilities-work-order) | A fault as a CAFM ticket |

Everything the console can do is reachable here, billed from the same balance, with the same error codes.

## Response headers

Every response carries `X-Voho-Engine`. Successful synthesis calls add the details of what was produced:

| Header | Example | Meaning |
| --- | --- | --- |
| `X-Voho-Engine` | `voho-speech/1` | API version, on every response. Reads `voho-api/1` on the agent and understanding endpoints |
| `X-Voho-Model` | `sada-1` | Model that produced the audio |
| `X-Voho-Voice` | `layla` | Voice used |
| `X-Voho-Format` | `mp3` | Audio format |
| `X-Voho-Sample-Rate` | `24000` | Sample rate in Hz |
| `X-Voho-Characters` | `142` | Characters billed |
| `X-Voho-Cost-Cents` | `1` | Cost of this call, in cents |

<Tip>
  `X-Voho-Characters` and `X-Voho-Cost-Cents` let you track spend per request without a separate usage call. Log them alongside your own request IDs.
</Tip>

## Credits

One balance funds every endpoint. Each is billed for the thing it produces, and the cost of each call comes back in `X-Voho-Cost-Cents`.

| What you called | Unit | Cents |
| --- | --- | --- |
| Synthesis on `sada-1` | 1,000 characters | 5 |
| Synthesis on `nabra-1` | 1,000 characters | 2 |
| [An agent turn](/api-reference/agents-reply) | Turn, plus the speech it speaks | 2 |
| [Transcription](/api-reference/transcribe) | Minute | 3 |
| [Extract](/api-reference/documents-extract), [ask](/api-reference/documents-ask), [redact](/api-reference/privacy-redact), [work order](/api-reference/facilities-work-order) | Run | 4 |

Cost is rounded up, so a very short request still costs at least one cent. The [text utilities](/api-reference/text-normalize) are free. They neither synthesise nor read anything.

When the balance reaches zero, every billable endpoint returns `402`:

```json
{ "error": { "code": "insufficient_credit", "message": "Your credit balance is exhausted. Top up to continue." } }
```

<Note>
  Streaming calls are billed after the stream finishes, so a synthesis that fails partway is not charged.
</Note>

## Errors

Errors are JSON with a stable `code` and a human-readable `message`. Branch on `code`, never on `message`.

```json
{ "error": { "code": "unknown_voice", "message": "Unknown voice \"nope\"." } }
```

See [Errors](/api-reference/errors) for the full list.

## Limits

- **Synthesis: 5,000 characters** per request. Longer text returns `text_too_long`, split it into sentences and concatenate the audio.
- **Uploads: 8 MB.** Documents are PDF, PNG, JPEG or WebP; audio is WAV, MP3, OGG, WebM or FLAC, up to 60 seconds.
- Files go up as `multipart/form-data` with the file attached, or as JSON with a base64 `file` and a `mime_type`. Both are accepted everywhere a file is.
